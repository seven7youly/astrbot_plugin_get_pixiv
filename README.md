# 星绘漫游

AstrBot 安全发图插件。本插件精简自 [astrbot_plugin_get_px](https://github.com/shitianyaa/astrbot_plugin_get_px)，仅保留获取图片功能，已移除签到功能。

- 首选图片源：[Lolicon API](https://api.lolicon.app/)，无需 Token
- 可选回退：Pixiv（需 `pixiv_refresh_token`）
- 内容安全：默认仅普通分级（`allow_r18` 可配置允许 R18）；内置安全词（r18、裸体、血腥等）逐词单独开关，在插件 WebUI「内容安全设置」页面中以开关按钮管理，默认全部开启；支持自定义屏蔽词
- 稳定性：0–7 天自然日去重、发送失败重试、临时文件自动清理

## 安装

1. 在 AstrBot WebUI 插件页安装本插件：
   - 下载本仓库 zip 后选择「导入压缩包」
   - 或粘贴仓库地址
2. 默认使用 Lolicon API，无需 Token；需要 Pixiv 作为备用时再填写 `pixiv_refresh_token`。

## 指令

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/pv [标签] [数量]` | 按标签搜索发图 | `/pv 初音ミク 3` |
| `/pv [数量]` | 无标签时随机发图 | `/pv 5` |
| `/pv [标签] [数量] r18` | 单次取消 R18 限制（仅本次生效） | `/pv 初音ミク 2 r18` |
| `/pv 安全词` | 查看全部内置与自定义安全词 | `/pv 安全词` |
| `/pv help` | 查看全部指令帮助 | `/pv help` |

## WebUI 内容安全设置

插件页提供「内容安全设置」面板，可逐词开关 36 个内置安全词（按下=启用，未按下=停用），添加/删除自定义屏蔽词，并提供「🔞 R18 限制开关」（按下=允许 R18，红色填充）。安全词的控制仅能在该页面进行。

## 自然语言触发

插件提供两种自然语言调用方式：

### 1. 规则式触发

开启 `auto_trigger_enabled` 后，群内直接发送以下文本即可触发发图，无需命令前缀、不依赖大模型：

| 触发语 | 效果 |
| --- | --- |
| `来一份图` | 1 张随机图片 |
| `来三张初音ミク图` | 搜索并发送 3 张 |
| `来张风景图` | 搜索并发送 1 张 |

### 2. LLM Tool（大模型自然语言调用）

接入 AstrBot 大模型（Agent）后，插件会注册一个 LLM 工具 `search_images`。AI 在对话中理解用户的自然语言意图，并自动调用该工具完成发图，无需命令前缀：

- 触发示例：「来张图」「发三张初音ミク的图」「随便来一张涩图」等，AI 会识别意图与参数并调用发图。
- 工具参数：
  - `tag`：插画搜索标签，可为空（随机取图）
  - `count`：发送的图片数量（1–5）
- 与指令 `/pv` 走同一套完整链路：内容安全过滤、单次 `r18` 处理、发图去重、下载与发送重试、失败附 Pixiv 链接。
- 同样受 `auto_trigger_enabled` 控制：关闭时 AI 调用会收到「自然语言发图未开启」的提示。
- 安全词开关、R18 限制等均由插件配置与 WebUI 统一管理，AI 调用同样生效。

> 二者区别：规则式触发是固定短语匹配，任意部署可用；LLM Tool 需 AstrBot 配置了可用的聊天大模型（Agent）才生效，但理解更灵活，支持任意表达方式。

## 平台支持

- QQ（OneBot / aiocqhttp）：完整支持，含合并转发。
- 微信：支持个人微信（`weixin_oc`）、企业微信（`wecom`）、微信公众平台（`weixin_official_account`），自动降级为逐条发送图片，不使用合并转发。
- 其他平台会尽量降级为逐条发送，请自行测试兼容性。

## 记录发送消息到对话

开启 `record_message_to_conversation`（默认开启）后，插件发图成功会把「用户请求（标签 / 数量）」和「已发送 N 张图片（作品 ID）」写入 AstrBot 的对话历史，让大模型 / AI 在后续对话中也能看到插件发送的消息，保持上下文连贯。

- 仅对已存在的对话记录生效（该会话曾进入过 AI 对话时才会写入），不影响纯插件使用场景。
- LLM 工具调用（`search_images`）由 AstrBot 框架自动记录工具结果，不会重复写入。
- 通过 `/pv` 指令或规则式自然语言触发发图时同样会记录。
- 可在插件配置中关闭该功能。
