# 星绘漫游

AstrBot 安全发图插件。本插件参考 [astrbot_plugin_get_px](https://github.com/shitianyaa/astrbot_plugin_get_px)，保留获取图片功能，并对其进行强化。

- 首选图片源：[Lolicon API](https://api.lolicon.app/)，无需 Token
- 可选回退：Pixiv（需 `pixiv_refresh_token`）
- 内容安全：🔞 始终只发送全年龄段图片；系统内置安全词（不可关闭），支持自定义屏蔽词
- 稳定性：0–7 天自然日去重、发送失败重试、临时文件自动清理

## 安装

1. 在 AstrBot WebUI 插件页安装本插件：
   - 下载本仓库 zip 后选择「导入压缩包」
   - 或粘贴仓库地址
2. 默认使用 Lolicon API，无需 Token；需要 Pixiv 作为备用时再填写 `pixiv_refresh_token`。

## 指令

| 指令 | 说明 | 示例 |
| --- | --- | --- |
| `/pv [标签] [数量]` | 按标签搜索发图 | `/pv 初音ミク 3` |
| `/pv [数量]` | 无标签时随机发图 | `/pv 5` |
| `/pv 安全词` | 查看全部内置与自定义安全词 | `/pv 安全词` |
| `/pv help` | 查看全部指令帮助 | `/pv help` |

## WebUI 设置页

插件页（星绘漫游设置）包含三个标签：

- **内容安全**：🔞 R18 已限制（仅发送全年龄段，不可修改）；系统内置安全词以只读形式展示（不可关闭），支持添加/删除自定义屏蔽词。
- **插件配置**：集中管理基础配置（图片源、Token、图片质量、去重、频率限制等），并与 AstrBot 配置面板同步生效。部分配置（如图片源地址、Token、反代地址）修改后需重载插件生效。
- **大语言模型（LLM）**：集中管理自然语言触发、记录发送结果到对话、发送后让大模型“看”图片、无结果更换标签重试、用大模型人格改写回复等 LLM 相关设置。

页面支持深色/浅色模式，并自动跟随 AstrBot WebUI 的主题同步切换。

## 自然语言触发

`auto_trigger_enabled` 默认开启。群内直接发送以下文本即可触发发图，无需命令前缀、不依赖大模型：

| 触发语 | 效果 |
| --- | --- |
| `来一份图` | 1 张随机图片 |
| `来三张初音ミク图` | 搜索并发送 3 张 |
| `来张风景图` | 搜索并发送 1 张 |

> 想让 AI 大模型理解任意自然语言并自动发图、或在发图后让大模型“看见”图片内容，请见下一节「大语言模型（LLM）应用」。

## 大语言模型（LLM）应用

以下功能均需 AstrBot 配置可用的聊天大模型（Agent），并受 `auto_trigger_enabled`（默认开启）统一控制：关闭时 AI 调用会收到「自然语言发图已关闭」的提示。

### 1. 大模型自然语言调用发图（LLM Tool）

插件注册了 LLM 工具 `search_images`。AI 在对话中理解用户的自然语言意图，并自动调用该工具完成发图，无需命令前缀：

- 触发示例：「来张图」「发三张初音ミク的图」「随便来一张涩图」等，AI 会识别意图与参数并调用发图。
- 工具参数：
  - `tag`：插画搜索标签，可为空（随机取图）
  - `count`：发送的图片数量（1–5）
- 与指令 `/pv` 走同一套完整链路：内容安全过滤（仅全年龄段）、发图去重、下载与发送重试、失败附 Pixiv 链接。系统内置安全词与 R18 限制对所有调用路径同样生效，AI 无法绕过。
- **无结果自动更换标签重试**：若初始标签在图片源上没有结果，不会立即提示失败，而是调用大模型更换/优化标签（如翻译成日语）重新搜索，最多重试 `llm_search_tag_retries`（0–5，默认 2）次；全部仍无结果才提示「图片源请求失败或无结果」。

### 2. 用大模型人格改写回复

开启 `llm_natural_replies`（默认开启）后，插件的功能提示（请求过于频繁、搜索无结果、下载失败等）不再由插件生硬输出，而是把当前场景**推送给 AstrBot 主 Agent**，由其在完整人格设定与对话上下文中自然回复（不限制字数，由主 Agent 自行判断）。回复会写入对话历史，让大模型/AI 在后续对话中也能看到插件发出的提示。无法调用大模型（未配置模型）时，使用默认回复文案兜底。自然语言调用（LLM 工具）时除外——此时由外层 Agent 收到工具结果后自然回应，插件不再嵌套推送。

### 3. 记录发送消息到对话

开启 `record_message_to_conversation`（默认开启）后，插件发图成功会把「用户请求（标签 / 数量）」和「已发送 N 张图片（作品 ID）」写入 AstrBot 的对话历史，让大模型 / AI 在后续对话中也能看到插件发送的消息，保持上下文连贯。

- 仅对已存在的对话记录生效（该会话曾进入过 AI 对话时才会写入），不影响纯插件使用场景。
- LLM 工具调用（`search_images`）由 AstrBot 框架自动记录工具结果，不会重复写入。
- 通过 `/pv` 指令或规则式自然语言触发发图时同样会记录。
- 可在插件配置中关闭该功能。

### 4. 发送后让大模型“看”图片

`llm_describe_images` 默认开启。插件发图成功会调用大模型查看已发送的图片并生成内容描述。图片转述**优先使用 AstrBot 配置的「默认图片转述模型」**（`provider_settings.default_image_caption_provider_id`），避免会话默认对话模型不支持多模态而失败；未配置时回退当前会话聊天模型。

- 描述**不会发送到聊天框**，只写入对话历史，让机器人对图片内容形成持久记忆，同时保持聊天平台的连续性（聊天里只有图片本身）。
- 描述会**绑定本次发图的搜索标签**：带标签时，大模型会被要求结合标签客观描述图片内容并判断是否与标签相符（随机取图无标签时仅使用基础提示词）。
- 指令/自然语言触发路径：描述随发送结果一起写入对话历史（`add_message_pair`）。
- LLM 工具路径：描述作为工具结果回传给大模型并由框架记录到对话，同样不会直发聊天框。
- 图片直接复用发图下载的临时文件，由大模型侧编码传输，**不新增任何磁盘占用**；临时文件仍会在发图流程结束后自动清理。
- 未找到可用聊天模型、模型不支持图片或调用失败时静默跳过，不影响发图。
- 描述提示词默认：
  > Please briefly describe the content and atmosphere of this image. If there are people in the image, please describe their actions, expressions, postures, clothing, and facial expressions in detail.
  可在 `llm_describe_prompt` 中自定义。

## 平台支持

- QQ（OneBot / aiocqhttp）：完整支持，含合并转发。
- QQ 官方机器人（`qq_official`）：按官方 API 适配，图片以标准组件发送。
- 微信：支持个人微信（`weixin_oc`），自动降级为逐条发送图片，不使用合并转发。
- 其他平台会尽量降级为逐条发送，请自行测试兼容性。

## 限制说明

- 🔞 出于安全考虑，插件**始终只发送全年龄段（普通分级）图片**，`r18` 指令、R18 开关等相关配置与 UI 均已锁定，不可通过任何方式开启。
- 内置安全词为**系统内置、不可关闭**（无法在配置或 UI 中修改）；仅可添加/删除自定义屏蔽词。
- 如有需求，请查看develop版本
